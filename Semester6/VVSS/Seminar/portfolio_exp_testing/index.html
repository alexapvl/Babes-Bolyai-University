Student Registration Form

Demo app for exploratory testing

This app intentionally contains validation defects for testing purposes.

Testing Mission

Explore the registration form using Bug Magnet. Focus on invalid emails, special characters, long inputs, weak passwords, unusual phone numbers, and boundary values for age.

Expected Findings

  • Weak email validation
  • Missing max length for full name
  • Unsafe reflection of comments
  • Permissive phone validation
  • Weak password rules
  • Incorrect age validation
